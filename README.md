# Loops

Three days of loops. Each day uses three files, in this order:

| Day | Topic | 1. Review | 2. Lesson | 3. Independent check |
| --- | --- | --- | --- | --- |
| 1 | `""` and `+` in a for loop | `ding_floor.py` | `pin_mask.py` | `code_readback.py` |
| 2 | Starting at 0, and `_` | `stop_count.py` | `bike_minutes.py` | `bus_riders.py` |
| 3 | `if` and `break` | `found_bang.py` | `area_code.py` | `clock_hour.py` |

## The files

- **Review** (first 7 minutes): a short snippet from earlier lessons, with two questions in the comments. Answer them right under each question.
- **Lesson:** one snippet, worked top to bottom: **PREDICT → RUN → INVESTIGATE → MODIFY → MAKE**. The comments tell you what to do at each stage. Edit the file as you go. If you fall behind, copy the current code from the screen and keep going.
- **Independent check:** **open only when your instructor says.** Work alone, with no AI and no notes, and write your prediction on paper before you run anything.

## How to work

- **Predict before you run.** Fill in every `# Prediction:` first. A wrong prediction is useful; an empty one isn't.
- **Stuck rule:** if you've been stuck for **5 minutes** or tried **two different things**, ask for help.
- **When you ask, bring four things:**
  1. the line you're looking at
  2. what you predicted
  3. what actually happened
  4. what you've tried so far
- **Checkpoints:** each lesson file has two `CHECKPOINT` lines, one after Investigate and one after Make. Show an instructor your work at each one before moving on.
